# Dinner Time

Unofficial personal recipe app for Dan and Adele.

- Home screen: tick the checkbox beside each recipe you want for the week. Tap a recipe name for its ingredients and steps.
- "Generate shopping list" button shows the combined ingredients for everything ticked.
- New recipes arrive through Muse: send a Facebook reel link, Muse extracts the recipe, and the next build includes it. The app itself is fully offline and does not pull Facebook live.

Build: GitHub Actions debug APK, with a fixed debug keystore so updates install over the installed app.
